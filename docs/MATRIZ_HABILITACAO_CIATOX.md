- ✅ comprovado;

- 🔴 ausente;
- ⚪ não avaliado.

## Produtos derivados

A matriz deverá gerar automaticamente:
1. percentual de requisitos avaliados;
2. percentual comprovado;
3. gaps críticos;
4. pendências por área;
5. documentos faltantes;
6. responsáveis e prazos;
7. status para habilitação;
8. status para qualificação.

## Regra

Nenhum item deve ser marcado como ✅ sem evidência documental identificada.
