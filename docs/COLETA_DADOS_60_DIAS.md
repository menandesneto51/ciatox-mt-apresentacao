# Plano de coleta de dados — estudo técnico de 60 dias

## Objetivo

Obter evidência suficiente para comparar, sem decisão antecipada, os cenários:

1. fortalecimento do CIAVE/CIATox Cuiabá;
2. cogestão/referência estadual;
3. novo CIATox estadual.

## Bloco A — CIAVE/CIATox existente

Solicitar, preferencialmente para os últimos 24–36 meses:

### Institucional
- CNES;
- unidade gestora;
- organograma;
- ato de criação;
- pactuações existentes;
- contratos/convênios;
- fontes de financiamento.

### Recursos humanos
- categoria profissional;
- quantidade;
- vínculo;
- carga horária;
- escala;
- cobertura noturna/finais de semana;
- titulação/formação em toxicologia;
- afastamentos e vacâncias.

### Produção
- chamadas/consultas por mês;
- origem por município;
- agente tóxico;
- circunstância;
- faixa etária;
- gravidade;
- conduta;
- encaminhamento;
- necessidade de transferência;
- desfecho, quando disponível;
- tempo-resposta.

### Infraestrutura
- telefonia;
- gravação/registro;
- estações de trabalho;
- conectividade;
- espaço físico;
- redundância elétrica/internet;
- sistemas utilizados.

### Qualidade
- protocolos;
- POP;
- indicadores;
- auditoria;
- registro de incidentes;
- plano de contingência.

- antídotos e soros;
- Lacen/rede de coleta;
- eventos toxicológicos prioritários;
- ponto focal proposto;
- gargalos;
- necessidades de capacitação.
